# Farhan Karim — Portfolio Website

## Run the website
1. Extract `farhan_portfolio_website.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in your browser.

For the best editing experience, open the folder in Visual Studio Code and use the Live Server extension.

## Files
- `index.html` — page content
- `style.css` — layout, colors, and responsive design
- `script.js` — mobile navigation and current year
- `assets/farhan.jpg` — your uploaded profile photo

## Personalize before publishing
- Check the project descriptions and links.
- Add your real email address and verified certification details.
- Add LinkedIn and other social profile links if you want them displayed.
- Add your CV PDF and link the header button to it if you want a downloadable CV.

The contact area currently links to your GitHub profile; it does not send messages to an inbox.
